# Catálogo de Agentes - Valorant
Projeto desenvolvido para a disciplina de Desenvolvimento Web III (Fatec Registro).

## Sobre o projeto
Aplicação front-end feita com React e Next.js que consome a API pública do Valorant (`valorant-api.com`) para listar os agentes jogáveis e exibir os detalhes e habilidades de cada um.

## Como rodar
1. Instale as dependências: `npm install`
2. Rode o servidor local: `npm run dev`
3. Acesse `http://localhost:3000`
